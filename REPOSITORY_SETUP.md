# Before publishing this repository

This project started as an experiment built on an ArcFace codebase. Before making it public, verify that you have the right to redistribute all inherited source files and assets. The original repository's license may not automatically cover every later addition or third-party component. Add the correct license only after checking the upstream license and ownership of your changes.

Checklist:

- [ ] Review all inherited source files and preserve required copyright / license notices.
- [ ] Confirm the dataset license permits publishing derived artifacts such as manifests and metrics.
- [ ] Confirm no raw EEG, personally identifying data, API tokens, secret keys, or local paths containing sensitive information are committed.
- [ ] Re-run the documented setup and API locally on a clean environment.
- [ ] Replace the placeholder repository link in `MEDIUM_ARTICLE.md` after publishing.
- [ ] Treat reported metrics as experimental and retain the caveats in the README and article.
